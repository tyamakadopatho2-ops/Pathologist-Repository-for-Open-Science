# Code Archive
This branch provides analysis code accompanying “Myofibre Density Reveals a Critical Threshold Around Age 6 in Steroid-Naïve Duchenne Muscular Dystrophy: A Retrospective Observational Study,” now published in Neuropathology and Applied Neurobiology.

This repository is intended to support computational reproducibility of the reported analyses. Analysis scripts and shareable supporting datasets are provided in this branch.


## How to cite
Please cite the published article as:

## Reproducibility notes (global)
Analyses were developed in R.

Where stochastic procedures were used, randomness was controlled with explicit set.seed(123) calls. Reproducibility may still depend on the R version, package versions and computing environment.


## World Muscle Society poster
The WMS poster summarises the main findings of this study for conference presentation, including age–MFD dynamics, age-predictive MFD thresholds, Bayesian/ROPE validation, cross-parameter histological validation and implications for the timing of therapeutic intervention in Duchenne muscular dystrophy.
The poster is provided as a conference presentation resource. Please cite the original article when using or referring to these materials.
