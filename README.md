This repository provides the analysis-record R scripts actually used for the study entitled “A myofibre-centred molecular phase reorganisation aligned with the clinicopathological critical period in Duchenne muscular dystrophy: Integrated human transcriptomics and mouse single-cell RNA sequencing.” The scripts are shared for transparency and documentation of the analytical workflow. They were executed in a local Windows project environment and contain implementation-specific paths to local input files, cached public/resource files, and intermediate RDS objects generated during the workflow. Users wishing to reuse or rerun the scripts should adapt file paths, directory structures, package versions, and resource locations to their own computational environment. These scripts are not provided as a fully containerized, one-command reproducibility pipeline; the processed numerical outputs supporting the manuscript are provided separately as Supplementary Data files.
