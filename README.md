# Code Archive
This branch provides analysis code accompanying “Myofibre Density Reveals a Critical Threshold around Age 6 in Steroid‑Naïve Duchenne Muscular Dystrophy: A Retrospective Observational Study,” which has been formally accepted for publication in Neuropathology and Applied Neurobiology. Full scripts and shareable datasets are available to support reproducibility.

## How to cite
Yamakado T et al. Myofibre Density Reveals a Critical Threshold around Age 6 in Steroid‑Naïve Duchenne Muscular Dystrophy: A Retrospective Observational Study. Neuropathol Appl Neurobiol (2026). [DOI will be provided upon publication]

In the interim, please cite the article as "accepted and forthcoming" and reference this repository and specific commit hash.

## Reproducibility notes (global)
Analyses were developed in R.  
Randomness is controlled with explicit `set.seed(123)` calls to ensure bit‑for‑bit repeatability.
