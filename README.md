This branch supports the manuscript “A myofiber-centered molecular phase reorganization aligned with the clinicopathological critical period in Duchenne muscular dystrophy: integrated human transcriptomics, mouse single-cell RNA sequencing, and histochemistry.”

The study integrates human skeletal muscle bulk microarray analysis, a fixed marker-annotated mouse skeletal muscle single-cell RNA sequencing dataset, and archival succinate dehydrogenase (SDH) with paired reduced nicotinamide adenine dinucleotide–tetrazolium reductase (NADH-TR) histochemistry.

During peer review, the analysis-record R scripts and fixed input files are provided through reviewer-only access and are not yet publicly released. The publication versions of the scripts will be added to this branch after the article is published.

The scripts were developed in a local Windows/R 4.5.x project environment and require adaptation of file paths and resource locations for reuse. They document the analytical workflow but are not a containerized one-command pipeline. Processed numerical results are supplied with the manuscript as Additional files.
